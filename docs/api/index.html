Resttek API (1.0.0)

Download OpenAPI specification:

API REST de Resttek, plataforma de gestión de restaurantes.

Autenticación: JWT en la cabecera Authorization: Bearer <token>. El token se obtiene en POST /api/v1/auth/login (o /auth/register para clientes) y caduca a las 8 horas.

Roles: admin, manager (gerente), cocinero, camarero, cliente. Los clientes son Employee con role='cliente' y restaurantId=null; por eso las respuestas de login/registro usan la clave employee también para ellos.

Errores: los errores de dominio se devuelven como { "error": "<NombreDelError>", "message": "..." } (400 por defecto, 404 para NotFound, 401 para credenciales inválidas). Los fallos de autenticación y autorización devuelven solo { "error": "..." }. Los mensajes de error están en inglés.
